# YouTube-channel

Контент-план и идеи для YouTube-канала (наука / космос / мозг / технологии).

- [`content-plan.md`](content-plan.md) — концепция канала, рубрики, 12 идей постов с хуками и структурой, стратегия запуска на 30 дней, чек-лист производства.
- [`shorts.md`](shorts.md) — 30 идей шортсов с хуками, текстом на экране и визуалом, плюс банк хуков.
- [`video/`](video/) — готовые шортсы на Remotion (код, озвучка, отрендеренные MP4 в `video/out/`): «Ты смотришь в прошлое» в двух голосах на выбор, «Тёмный лес» и «Мозг решил до тебя». Инструкция — в `video/README.md`.
